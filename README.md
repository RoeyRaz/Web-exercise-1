# תרגול 1 בתכנות Web — מדריך למתחילים

זהו פרויקט HTML קטן עם ארבעה דפים וקישורים ביניהם. הקוד נכתב לצורכי למידה, והוא תואם לדרישות תרגול הכיתה הראשון. תמונות כלי הנגינה הן איורי SVG מקומיים, ולכן האתר עובד גם ללא אינטרנט.

## פתיחה ב־VS Code

1. חלצו את קובץ ה־ZIP לתיקייה במחשב.
2. פתחו VS Code, בחרו `File → Open Folder`, ובחרו את התיקייה `web-exercise-1`.
3. בצד שמאל, בחלונית `Explorer`, פתחו את `main.html`.
4. לשמירה השתמשו ב־`Ctrl+S`.
5. להצגת האתר, פתחו את הקובץ `main.html` בדפדפן. אפשר גם להשתמש ב־`Open in Integrated Browser` בגרסאות VS Code שבהן האפשרות זמינה.

אין צורך ב־Node.js, ב־npm, ב־React או בשרת בשביל התרגול הזה.

## מה עושה כל קובץ

- `main.html` — עמוד הבית, פסקאות ורשימה ממוספרת.
- `about.html` — אודות ומייל לדוגמה שאינו פרטי קשר אמיתיים.
- `flute.html` — מידע, תמונה וטבלה של חלילים.
- `drums.html` — מידע, תמונה וטבלה של תופים.
- `style.css` — עיצוב בסיסי, תוספת לנוחות בלבד.
- `images/` — האיורים המקומיים שנטענים בעזרת `<img>`.

## מושגים לזכור

| תגית | תפקידה |
| --- | --- |
| `<title>` | שם הלשונית בדפדפן, בתוך `<head>` |
| `<h1>` | כותרת ראשית שמופיעה בדף |
| `<p>` | פסקה |
| `<ul>` + `<li>` | רשימה לא ממוספרת |
| `<ol>` + `<li>` | רשימה ממוספרת |
| `<a href="about.html">` | קישור לדף אודות |
| `<img src="images/flute.svg" alt="...">` | תמונה והטקסט החלופי שלה |
| `<table>`, `<tr>`, `<th>`, `<td>` | טבלה, שורה, תא כותרת ותא נתונים |
